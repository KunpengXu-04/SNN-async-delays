### What was going on here:
*   **Setup**: We sequentially feed Query 0, Query 1, Query 2 into the SNN. Time and query count are coupled ($T = 10K + 10$).
*   **The "Cheating" parts that made it work**:
    1.  **MLP Readout**: The hidden layer was decoded using a non-spiking multi-layer perceptron (MLP). This is not a neuromorphic end-to-end spiking network.
    2.  **Rate Encoding**: We used continuous Poisson rate inputs (400 Hz). This generated a massive number of spikes, meaning the network had constant voltage fluctuations and never ran into "silent gradient zones." It was highly energy-inefficient.
    3.  **Pooled Accuracy**: The metrics averaged all queries. If the late queries were correct but early queries failed, the average still looked okay, masking the routing failures.

### The Re重构 (Re-scaffolding) for XOR:
To make this scientifically rigorous, I pivoted the experiments to:
*   **Spiking Output**: Class-opponent LIF neurons at the output. A spike *must* land at exactly step 15 (no MLP allowed).
*   **Burst Input**: Precise micro-bursts (steps 8 and 9) to keep spike counts sparse.
*   **Worst-query Accuracy**: If any single query timing or classification fails, the whole trial fails.
This made optimization much harder, which is why we had to build up from Level 1A to see what was broken.

## 3. Deducing the Bankruptcy of Autonomous Time-Multiplexing

Here is the most important conclusion from the **Timing Withdrawal Experiment (timing_withdrawal_v1)**:

We trained a network perfectly with the teacher (W0). Then we damaged the delays slightly (shifted them to 3 or 5 steps), removed the teacher, and asked the network to recover using **only the task classification loss** (W2 stage, `task_delay_only` condition).

**The recovery failed 0/10 completely.** The delays could not return to 4.0. 

### Why Autonomous Delay Learning Under Task Loss is Mathematically Bankrupt:

1.  **Surrogate Gradient Deadlock**:
    When delays are wrong (e.g. 3 or 5 steps instead of 4), the spikes arrive outside the target window. 
    Inside the target window, the output LIF neuron is silent. Its voltage is exactly $0$.
    Since the voltage is far below the threshold $\theta$, the surrogate gradient of the LIF threshold is **exactly zero**:
    $$\sigma'(V - \theta) = \sigma'(0 - 0.03) \approx 0$$
    **This physically cuts off the backpropagation path.** The delays receive exactly zero gradient.
2.  **Causal Filter Asymmetry**:
    SNN membrane potentials decay forward in time. This causal asymmetry means the gradient field only pulls in one direction. It cannot symmetrically push early spikes later or pull late spikes earlier, causing the optimizer to push parameters into dead boundary zones.
3.  **Weight Compensation Traps**:
    Instead of correcting the delays, the optimizer simply adapts the weights to classify whatever early activity is present, locking the network into a local minimum where the delays remain wrong but the weights try to compensate.

### The Bottom Line:
We **cannot** claim that SNNs can autonomously discover time-multiplexed routing schedules from task labels alone. That claim is bankrupt. 

However, **time-multiplexing as a representation is highly valid** (as proven by our 100% accurate Fixed Oracle which saves 50% hidden area). 

Therefore, our paper should be framed as: **characterizing the fundamental boundary of delay optimization, proving the necessity of coordinate-matched timing scaffolds for symmetry breaking, and validating a two-stage pre-train (scaffold) + fine-tune (withdrawal) curriculum.**
